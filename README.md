# BasketFX - Unified Expert Advisor

## 🎯 Project Goal
This project aims to unify 9 separate MetaTrader 4 Expert Advisor (EA) MQ4 files into a single, comprehensive MQ4 file that can be compiled into one .ex4 file for use in MetaTrader 4.

## 🚀 Features (Planned)

Once the source files are provided, the unified EA will include:

- ✅ All 9 trading strategies in one file
- ✅ Individual enable/disable switches for each strategy
- ✅ Configurable parameters for each strategy
- ✅ Unified risk management system
- ✅ Strategy-specific magic numbers for trade tracking
- ✅ Daily loss limits and trade count limits
- ✅ Easy-to-use parameter interface
- ✅ Single .ex4 file for MetaTrader 4

## 🔧 How It Will Work

1. **Upload Files**: Provide 9 MQ4 files + documentation
2. **Integration**: All strategies merged into one file
3. **Configuration**: Parameters organized for easy setup
4. **Compilation**: Single MQ4 file ready to compile
5. **Usage**: One .ex4 file to attach to any MT4 chart
